隐私政策

1. 收集的信息

本应用不收集、不存储、不传输任何个人信息。
所有数据仅保存在用户本地设备中，不会离开用户的计算机。

3. 权限说明

权限用途是否必须
文件系统读写读写数据/日志文件✅
管理员身份运行某些游戏需要❌

2. 本地数据说明（最小化原则）

数据类型用途存储位置加密可配
工作流配置生成工作流%APPDATA%/Local/io.github.xiaobenshou/data/✅✅
用户设置APP 用户配置xiaobenshou/conf/❌❌
嵌入组件数据提升性能%APPDATA%/Local/io.github.xiaobenshou/EBWebView/✅❌
日志数量记录运行日志%APPDATA%/Local/io.github.xiaobenshou/logs/❌ 可随时清理❌

4. 第三方共享与披露

  • 不存在向第三方共享、转让、公开披露个人信息的情形；
  • 不存在跨境数据传输；

5. 数据保留与删除

  • 所有数据保存在 本地磁盘， 保留期限由用户决定；
  • 用户也可手动删除日志数据，无需联系【小笨手】。
  • 卸载应用时 xiaobenshou/config/* 会自动删除，%APPDATA%/Local/io.github.xiaobenshou/* 需要手动删除

6. 儿童隐私

本应用面向 成年人。
如用户是未成年人，请在监护人指导下使用，并确保监护人已阅读本政策。

7. 政策更新

【小笨手】可能会随版本更新对本政策进行修订，修订后的政策随软件安装包一起提供，不再单独推送通知。

参考

  2. 《GB/T 35273》
