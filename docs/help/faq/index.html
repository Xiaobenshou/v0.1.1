常见问题

1. 在游戏自动按键没反应

解决办法：
(a) 排查问题
将输入法切换到英文输入法，打开任意文本编辑器，在编辑模式触发【任务】,查看【子任务】的自动按键是否能在编辑器打印相应的英文字母。如果编辑器没有打印就是配置问题。如果编辑器有打印，游戏窗口却没响应的自动按键触发，说明是权限问题。
(b) 权限问题的处理办法
右键点击桌面快捷方式，选择“以管理员身份运行”的方式运行【小笨手】。

  • 如果依然没期望的输出，说明该游戏屏蔽了操作系统 API 的键鼠输入而是从驱动获取输入，目前版本的小笨手没法处理这种情况。
  • 如果无法选择“以管理员身份运行”的方式运行【小笨手】，参照安装文档安装最新版本。

2. 当前版本已不再维护

解决办法：
参照安装文档安装最新版本。

3. 网络链接

日志提示:
network request error: 不知道这样的主机。 (os error 11001)

解决办法：
保持网络链接，【小笨手】需要下载少量资源(几 kb 大小，缓存在内存中)

4. DNS 污染类型错误/证书类错误

这个系列的错误也属于 DNS 污染类型错误，导致系统将 xiaobenshou.github.io 解析到错误的 IP。

日志提示:

  • error sending request for url (https://xiaobenshou.github.io/v0.1.1)
  • No connection could be made because the target machine actively refused it. (os error 10061)
  • invalid peer certificate: UnknownIssuer

解决办法：
(a) 检查 C:/Windows/System32/drivers/etc/hosts 文件是否包含 xiaobenshou.github.io 相关的记录。如果有直接删除即可。
(b) 检查 Windows 系统的 DNS 配置，是否使用了不可用的配置。
